# Forge Mobile UI

Мобильный веб-интерфейс (PWA) для **Stable Diffusion WebUI Forge Neo**.
Полностью дублирует работу вкладок **txt2img**, **img2img**, **Extras** и
**Infinite image browsing**, включая установленные расширения, и оптимизирован
для iPhone/Android.

```
http://<ip-компьютера>:9595
```

---

## Запуск

Сервер поднимается автоматически вместе с Forge из `RUN-Sage.bat`
(отдельное свёрнутое окно «Forge MobileUI»). Он стартует сразу и ждёт,
пока Forge поднимет API, поэтому страницу можно открыть заранее — она сама
подключится.

Отдельный запуск (если Forge уже работает):

```bat
MobileUI\start.bat
```

Параметры командной строки:

| Ключ | По умолчанию | Назначение |
|------|--------------|------------|
| `--host` | `0.0.0.0` | Интерфейс прослушивания |
| `--port` | `9595` | Порт |
| `--forge` | `http://127.0.0.1:7860` | Адрес API Forge |
| `--dev` | — | Подробный лог запросов |

Зависимостей нет — только стандартная библиотека Python (PIL используется
опционально, для миниатюр превью LoRA).

### Установка на iPhone как приложение

1. Открыть `http://<ip>:9595` в Safari.
2. «Поделиться» → **На экран «Домой»**.
3. Приложение запускается в полноэкранном режиме, с учётом «чёлки»
   и безопасных зон, без адресной строки.

> Service Worker (офлайн-кеш) браузеры включают только в защищённом контексте
> (https или localhost), поэтому при доступе по IP он не регистрируется —
> на работу интерфейса это не влияет.

## Возможности

### Референсы персонажа (карточки как основа генерации)
Блок «Референсы персонажа» есть в txt2img и img2img; **по умолчанию выключен** —
включается переключателем «Использовать референсы». Он отправляет изображения
в Forge через alwayson-скрипт **ImageStitch Integrated**
(`args = [true, [base64, …], maxSide]`), а для **FLUX.2 Klein** при включённой
опции `klein_do_reference` это переводит модель в режим Edit: изображения
становятся `ref_latents`, и генерация опирается на них.
Работает так же для Flux.1-Kontext, Qwen-Image-Edit, Anima Edit, Krea2 Edit.

Два способа:

* **Разовые изображения** — «Добавить» / «Камера» / «Из папок». Живут в памяти
  вкладки, уходят в запрос напрямую.
* **Библиотека персонажей** — кнопка «Персонажи». Загружаете лист-карточку
  (turnaround со всеми видами), сервер **автоматически нарезает её на панели**
  рекурсивным XY-разрезанием, вы отмечаете 2–4 нужных вида (обычно фас, профиль,
  спина и портрет) и сохраняете персонажа с именем и текстовым описанием.
  Дальше персонаж выбирается одним нажатием, а его референсы подставляет сервер —
  на телефон они не гоняются. Кнопка «Промпт» дописывает описание в текущий промпт.

Персонажи лежат в `MobileUI/characters/<id>/` (`meta.json` + `refNN.png`) и
доступны с любого устройства. Ползунок «Максимальная сторона референса»
управляет качеством/скоростью (по умолчанию 1024).

Карточку можно подавать и целиком, без нарезки — Klein разбирается в листе,
но мелкие панели теряют детали при сжатии до максимальной стороны.

### Config Presets
Пресеты расширения **Config-Presets** читаются напрямую из его конфигов
(`config-txt2img.json` / `config-img2img.json`) и применяются к мобильному
интерфейсу: основные параметры, Hires.fix, промпты и стили, а также юниты
**ControlNet** и **ADetailer**. Текущие настройки можно сохранить как новый
пресет (перед первой записью создаётся резервная копия `*.mobileui.bak`) или
удалить существующий — изменения видит и обычный интерфейс Forge.

### txt2img
- промпт/негатив, счётчик тегов, обмен промптами местами;
- история промптов: восстановление, удаление отдельных записей и полная очистка;
- вставка **LoRA** (плиточный каталог с превью) и **embeddings**;
- **стили** (мультивыбор из библиотеки Forge);
- сэмплер, планировщик, шаги, CFG, **Distilled CFG**;
- размеры: **пресеты, сгруппированные по Square / Portrait / Landscape**
  (1024×1024; 640×1536, 768×1344, 832×1216, 896×1152 и зеркальные горизонтальные),
  кнопка «＋» добавляет текущий размер в свой пресет — он попадает в нужную
  группу автоматически и удаляется долгим нажатием; рядом обмен W/H и свободные
  слайдеры;
- batch count / batch size, seed (случайный/повтор предыдущего), subseed и
  вариации, seed resize, tiling, CLIP skip;
- **Hires. fix** целиком: апскейлер (включая latent-режимы), множитель, denoise,
  шаги, resize X/Y, отдельные CFG/Distilled CFG, сэмплер, планировщик и промпты;
- живой предпросмотр генерации, прогресс, прерывание и пропуск;
- все **alwayson-расширения** Forge (см. ниже);
- **скрипты**: X/Y/Z plot, Prompt Matrix, Prompts from file, One Button Prompt,
  Differential Regional Prompter и любые другие — панель строится автоматически.

### img2img
- источник: галерея телефона, камера, папки Forge, результат из txt2img/Extras;
- режимы **img2img**, **Скетч** (рисование цветом поверх изображения) и
  **Inpaint** с рисованием маски пальцем (кисть/ластик/инверсия/заливка/отмена);
- параметры инпейнта: размытие маски, содержимое под маской, область
  (всё изображение / только маска), отступ, инверсия маски;
- denoise, режим масштабирования, размер результата «W×H» или «множитель»
  с подсказкой итогового разрешения в мегапикселях;
- **автоподбор безопасного размера**: снимок с телефона (например 3024×4032)
  вписывается в ~1.1 Мп с сохранением пропорций и кратностью 16 — иначе
  диффузия в исходном разрешении переполняет VRAM и Forge падает
  (access violation в `c10.dll`). Автоподбор отключается переключателем,
  кнопка «Подогнать под безопасный размер» применяет его вручную;
  при >2.4 Мп показывается предупреждение, при >4 Мп запуск блокируется;
- все прочие параметры и расширения — как в txt2img.

### Extras
- **Апскейл**: множитель или целевой размер, два апскейлера с видимостью,
  обрезка, GFPGAN/CodeFormer, порядок операций; **пакетная обработка**
  нескольких файлов сразу;
- **Фон**: rembg (все модели, маска, alpha matting и пороги);
- **Лица**: ReActor (модель, индексы лиц, восстановление, апскейл, пол,
  порог и число детекций, устройство CPU/CUDA);
- **Ретушь**: восстановление старых фото (царапины, HR, лица, CPU);
- **CLIP**: интеррогатор (все модели open_clip, режимы best/fast/classic/negative)
  с отправкой результата в промпт;
- **PNG Info**: чтение метаданных и применение параметров к txt2img.

### Галерея (Infinite image browsing)
- все выходные папки Forge (txt2img, img2img, extras, сохранённые, сетки,
  видео, init-изображения) и дополнительные пути IIB;
- сетка миниатюр 2/3/4 колонки, ленивая подгрузка, сортировка;
- **поиск по промпту** по индексу базы IIB, поиск по тегам, случайные изображения,
  обновление индекса и статистика;
- просмотр с pinch-zoom и свайпами, метаданные генерации;
- отправка в img2img / Extras, применение параметров к txt2img, скачивание,
  удаление (в том числе множественное).

### Расширения
Панели расширений **строятся автоматически** из `/sdapi/v1/script-info`, поэтому
доступны все установленные alwayson-скрипты с полным набором параметров:
ADetailer (4 юнита), ControlNet (3 юнита с загрузкой изображения и маски),
Regional Prompter, Detail Daemon, TeaCache, ReActor, Forge FluxKontext,
Soft Inpainting, MultiDiffusion, ImageStitch, Spectrum, SDXL Styles,
Fooocus Expansion, LoRA Keywords Finder, Never OOM, Torch Compile и любые
новые, которые появятся в Forge позднее — интерфейс подхватит их сам.

**Изображения в панелях расширений.** В `script-info` такие аргументы приходят
как `null`, поэтому распознаются по названию скрипта и подписи: ReActor —
«Лицо-источник», Forge FluxKontext — «Референс 1 / 2». Для них рисуется
полноценный пикер (галерея / камера / папки Forge), а base64 подставляется в
`args` при сборке запроса. Сами изображения держатся только в памяти вкладки —
в localStorage они не поместились бы. Аргументы, которые через API не работают
(ReActor «Multiple Source Images» — список файлов, polymask Regional Prompter —
помечен нерабочим в самом расширении), намеренно не показываются.

**Списки с `type="index"`.** Часть Radio/Dropdown в расширениях отдаёт скрипту
номер варианта, а не текст, но в `script-info` приходит именно текст. Если
отправить текст, расширение молча ничего не делает — например, ReActor
сравнивает `select_source == 0`, а получив строку `"Image(s)"`, пропускает
замену лица. Такие аргументы перечислены в `INDEX_ARGS` (extensions.js) и
конвертируются в индекс при сборке запроса: ReActor — Console Log Level,
Gender Detection ×2, Select Source; Ultimate SD Upscale — Upscaler, Redraw type,
Seams fix type, Target size type.

Расширение отправляется в Forge только если его параметры отличаются от
значений по умолчанию; активные панели помечаются оранжевой точкой.
Кнопка «Сбросить» возвращает панель к дефолту вместе с загруженными картинками.

### Модель и система
Кнопка с кубом в шапке: смена чекпоинта, VAE/Text Encoder (мультивыбор),
UI Preset (sd / xl / flux / klein / qwen / …), Diffusion in Low Bits,
обновление списков моделей и LoRA, выгрузка модели из VRAM.
Кнопка «шестерёнка»: тема (тёмная/светлая/системная), живой предпросмотр,
удержание экрана, сохранение результатов на ПК, статистика VRAM/RAM,
сброс настроек и ссылка на полный интерфейс Forge.

## Как это устроено

```
MobileUI/
├─ server.py          сервер: статика + прокси к Forge + агрегатор справочников
├─ start.bat          автономный запуск
├─ cache/             миниатюры превью LoRA
└─ web/
   ├─ index.html      каркас приложения
   ├─ manifest.webmanifest, sw.js, icons/
   ├─ css/app.css     тема, компоненты, safe-area
   └─ js/
      ├─ app.js        роутинг вкладок, глобальные события
      ├─ core.js       DOM/API/шторки/лайтбокс/утилиты
      ├─ ui.js         слайдеры, селекты, переключатели, аккордеоны, пикер картинок
      ├─ state.js      состояние, загрузка справочников, пресеты
      ├─ gen.js        общие блоки формы, payload, генерация, прогресс, infotext
      ├─ extensions.js автоматический UI расширений из script-info
      ├─ presets.js    Config Presets: чтение, применение, сохранение
      ├─ characters.js референсы персонажа и библиотека (ImageStitch)
      ├─ t2i.js / i2i.js / mask.js / extras.js / browser.js / settings.js
```

Эндпоинты сервера:

| Путь | Назначение |
|------|------------|
| `/` | приложение |
| `/api/bootstrap` | все справочники Forge одним запросом (кеш 45 с) |
| `/api/loras`, `/api/embeddings` | облегчённые списки (без метаданных, кеш 30 мин) |
| `/api/thumb?path=…` | миниатюра превью LoRA (WebP, дисковый кеш) |
| `/api/folders` | выходные папки для галереи |
| `/api/presets` | GET — пресеты Config-Presets, POST — сохранение/удаление |
| `/api/characters` | GET — список персонажей; POST — `save` / `delete` / `slice` (автонарезка листа) |
| `/api/char-image?id=…&ref=…` | референс персонажа (с опциональным `size` — миниатюра) |
| `/api/generate/txt2img`, `/api/generate/img2img` | генерация с подстановкой референсов выбранного персонажа на стороне сервера |
| `/api/refresh` | обновление списков моделей/LoRA/VAE/embeddings |
| `/api/health` | доступность Forge |
| `/forge/*` | прозрачный прокси к Forge (`/sdapi/…`, `/infinite_image_browsing/…`, `/rembg`, `/reactor/…`, `/bopb2l/…`, `/interrogator/…`, `/controlnet/…`) |

## Примечания

- Результаты txt2img и img2img сохраняются в `output` Forge (переключатель в
  настройках). Extras-операции идут через API, который не пишет файлы на диск —
  результат скачивается на телефон кнопкой «Сохранить».
- Forge обрабатывает запросы последовательно: пока идёт генерация из основного
  интерфейса, мобильный запрос дождётся своей очереди.
- Настройки, промпты и параметры расширений хранятся в localStorage телефона
  отдельно для txt2img и img2img.
